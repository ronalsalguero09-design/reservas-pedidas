PROGRAMA: RESERVAS DE PEDIDAS DE NOVIOS

INSTALACIÓN EN VISUAL STUDIO CODE
1. Descomprime Reservas_Pedidas_Python.zip.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta y elige Reservas_Pedidas_Python.
4. Abre Terminal > Nueva terminal.
5. Ejecuta: python app.py
   Si no funciona, prueba: py app.py

ADMINISTRADOR
Contraseña inicial: 1234
Puedes cambiarla en app.py, en la línea CLAVE_ADMIN = "1234".

DATOS
El programa guarda las reservas en reservas_pedidas.json. Conserva ese archivo
para no perder las reservas.

IMPORTANTE
Esta versión funciona en una sola computadora. No publica el calendario en
Internet ni comparte reservas automáticamente con teléfonos ajenos. Para eso
se necesita una versión web con base de datos compartida.
